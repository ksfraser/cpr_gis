# CP Mountain Section — Gym Setup  [-comp]

The `-comp` module plan (`cpr_module_plan-comp.md`) and the `-proto` 1:1000 designs draw the section as a **straight west→east strip and do NOT include curves**. To set it up in a gym the strip is folded into **N parallel runs** joined by **180° return loops** (a dogbone for N=2, a serpentine for N≥3). The loops are a *gym artifact* — they are not part of the -proto, which is why the proto has few curves.

Folding rule: **N runs = N−1 loops**. Each run is a stretch of the single-track main with its yards/sidings; the return loops use radius **30 in** (Free-mo minimum 24 in; 30 in keeps the 89-ft well-car train comfortable).

## Operations (gym dogbone)

- Trains leave the west end (Revelstoke) through scenes A–C, take the 180° return loop, and come back through D–F to the east end (Field) — continuous running with one turn.
- The two ends (Revelstoke yard / Field yard) sit at the front of the gym; the loop(s) stick out the back/ends.
- Add a second 180° loop at the front (a true oval) only if pure continuous running is wanted; the dogbone already gives a full continuous lap because the two end yards join the runs.
- Curve grade: keep the loops flat (yards are flat anyway); the scene grades (±2.5% cap) stay on the straight runs.

Footprint: length = longest run + 5 ft for the loop overhang; width = runs × module depth + aisles + aisle to wall.
